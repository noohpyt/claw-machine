# 抓娃娃机 · Claw Machine

一个纯 HTML/Canvas 的抓娃娃机小游戏，无需任何构建工具，打开 `index.html` 即可玩。支持键盘与触屏操作，内置 WebAudio 合成音效。

## 玩法

- 按 `← →` / `A D` 移动爪子到目标上方。
- 按 `空格` / `↓` 下爪抓取娃娃。
- 抓起娃娃后运到左侧洞口（HOLE）上方，再次下爪或等待爪子松开，让娃娃落入洞口得分。
- 成功抓取并投入洞口 +100 分，尝试次数 +1；失败可点击「重置」重新摆放娃娃。

触屏设备会自动显示左右移动和抓取按钮。

## 特性

- 6 种不同外形的娃娃（熊、兔、猫、猪、青蛙、企鹅），每种有独特的配色与耳朵形状。
- 复合刚体物理：每个娃娃由身体和头部两个碰撞圆组成，抓取和掉落都有真实摆动。
- 爪子开合、上升、平移的完整状态机。
- 自适应画布缩放，适配不同屏幕尺寸。
- 全部音效通过 WebAudio API 实时合成，无外部音频文件。

## 技术栈

- 原生 HTML5 Canvas
- 原生 JavaScript（ES5/ES6 混合，无框架）
- CSS3 响应式布局
- WebAudio API

## 运行方式

无需安装依赖，直接用浏览器打开：

```bash
# 本地任意静态服务器均可
npx serve .
# 或直接用浏览器打开 index.html
```

## 文件结构

```
claw-machine/

├── style.css     # 样式与 UI 布局
└── game.js       # 游戏主逻辑、物理、渲染、音效
```
